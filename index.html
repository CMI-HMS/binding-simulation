Ideal conditions

The two models

Both describe one ligand binding one site. They differ in whether the protein is allowed to consume the ligand it binds.

specific binding f = LTn ⁄ ( K + LTn )

quadratic 1:1 f = [ (PT+LT+Kd)
           − √((PT+LT+Kd)² − 4PTLT) ] ⁄ 2PT

The first assumes free ligand equals what you pipetted in. The second solves mass balance for both partners, so it needs [P]T and is strictly 1:1 — there is no Hill exponent to fit.

EC50 vs Kd

The EC50 is the half-saturating concentration — the midpoint of the curve, and what a titration actually measures. It equals the Kd only when the protein is dilute.

EC50 = Kd + n·[P]T/2 — at any affinity.

The specific binding model has no term for depletion, so its half-saturation K1/n drifts toward the EC50 instead of the true Kd. Watch it happen on the plot: each model’s fitted Kd sits below the axis, the true EC50 on it. When the specific fit’s mark slides up to meet the diamond, depletion has taken over and the number it reports is the EC50, not an affinity.

The Hill coefficient

Raising n steepens the curve — a switch instead of a dimmer. Half saturation sits where Ln = K, that is at L = K1/n, so K and n set the position together: raise n at fixed K and the curve both steepens and shifts. Hold K1/n fixed instead and n changes steepness alone.

10% to 90% occupancy spans 811/n-fold in Lf

That is 81-fold at n = 1 and about 3-fold at n = 4. Fitting cooperative data with n locked at 1 cannot reproduce that steepness, and the fit pays for it in both K and residuals.

But n is a shape parameter, not a count of sites. A fitted value of 2.3 does not mean 2.3 of anything — use it to describe steepness, and say so.

What this assumes

  • True equilibrium. Nothing here is kinetic.
  • One kind of site. Two independent site classes need a different model.
  • Noise is Gaussian and constant across the curve, with no proportional error and no outliers.
  • [P]T is known and active. The quadratic fit is given the true value; in a real fit an inactive fraction biases it.
  • Noise is unbounded. Gaussian error is added to the true fraction with no clipping, so points can land below 0 or above 1 — as a real normalised readout does.
  • Units are labels. Everything shares one unit; switching it rescales nothing.

About this simulation

The data are generated from exact mass balance using each ligand's true Kd and Hill coefficient — never from the model being fitted. With n = 1 and dilute protein the two models describe the same curve, so any gap you see between them is depletion.

Every curve is sampled at 12 concentrations spaced logarithmically across that ligand's titration range; the Log x / Linear x toggle changes only the display, never the sampling. Points are the replicate mean, and bars are ±1 SD of those replicates, drawn only when there are two or more.

Fits minimise the sum of squares over every replicate point, not over the means, with Bmax fixed at 1 and the quadratic fit given the true [P]T. Standard errors are asymptotic, from the Gauss–Newton approximation to the least-squares curvature at the optimum. Noise is seeded per ligand, so the same settings always reproduce the same dataset.
